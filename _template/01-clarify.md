# 01-clarify — 要件明確化・サブ質問分解

## 役割
`prompt.md` の調査目的を具体的なサブ質問に分解し、調査スコープと成功基準を定義する。

## 参照パターン
gpt-researcher の Planner-Executor パターン（サブ質問分解）

---

## 実行手順

### Step 1: prompt.md を読み込む

`prompt.md` の内容をすべて読み込む。

### Step 2: 調査目的を分析する

目的文から以下の要素を抽出する:
- 主体（誰の視点か）
- 対象（何を調査するか）
- 目標（何を明らかにしたいか）
- 用途（結果をどう使うか）

### Step 3: サブ質問を生成する

以下のカテゴリから調査目的に応じた **5〜10 個のサブ質問** を生成する。
各サブ質問は「一つのことだけ聞く」単一質問にする。

**競合調査の標準カテゴリ:**

| カテゴリ | サブ質問の例 |
|---|---|
| 競合の特定 | 主要競合は何社か、それぞれの概要は何か |
| 製品・機能比較 | 各競合の主要機能と差別化要素は何か |
| 市場シェア・規模 | 市場規模と各競合のシェアはどの程度か |
| ビジネスモデル | 各競合の収益モデルと価格戦略は何か |
| 技術・特許 | 技術的な優位性や特許保有状況はどうか |
| 資金・財務 | 調達額・売上・黒字化状況はどうか |
| 顧客・評判 | 主要顧客層とユーザー評価はどうか |
| 最新動向 | 直近6〜12ヶ月の新展開・ニュースは何か |
| 脅威・リスク | 自社への直接的な脅威は何か |
| 市場トレンド | 業界全体のトレンドと将来予測は何か |

### Step 4: 各サブ質問を評価する

各サブ質問に対して:

```json
{
  "id": "Q01",
  "category": "競合の特定",
  "text": "主要競合企業は何社で、それぞれの事業概要は何か？",
  "priority": "High",
  "languages": ["ja", "en"],
  "source_types": ["official", "news", "database"],
  "estimated_sources": 10
}
```

- `priority`: High（調査目的の核心）/ Medium（補完情報）/ Low（参考情報）
- `languages`: 検索する言語（prompt.md の優先言語を参照）
- `source_types`: `official`（公式サイト）/ `news`（報道）/ `academic`（論文）/ `database`（DB/統計）/ `sns`（口コミ）

### Step 5: スコープを定義する

**調査する（In-scope）:**
- prompt.md の調査対象・目的に直接関連するもの
- 設定された地理・時間スコープ内のもの

**調査しない（Out-of-scope）:**
- prompt.md の除外条件に記載されたもの
- 直接関連しない周辺情報

### Step 6: 成功基準を定義する

「この調査が完了したと判断する条件」を 3〜5 項目で定義する。
例:「主要競合 5 社以上の製品・価格・シェアが confirmed ステータスで揃っている」

---

## 出力

`data/{セッション}/clarify.json` に保存する:

```json
{
  "session": "YYYY-MM-DD_{テーマ名}",
  "objective": "...",
  "sub_questions": [...],
  "scope": {
    "in": [...],
    "out": [...]
  },
  "success_criteria": [...]
}
```

完了後「要件明確化完了: {N}個のサブ質問を生成しました」と表示する。
